## 1. Revised architecture

Preserve Safety + Project Brain + MCP. Add modular layers under `src/`:

```text
agentdoctor (CLI / library / Action / MCP / local dashboard)
│
├── safety/ ............... EXISTING scan · rules · scoring · policy · Action
├── agents/ ............... EXISTING + Unreleased adapters (land in Phase I)
├── fix/ .................. EXISTING writers + Safe Fix 2.0 (backup/undo/audit)
│
├── understanding/brain/ .. EXISTING Project Brain store
├── brain-cli/ ............ NEW façade: init/status/inspect/snapshot/history/search/export/import
├── mcp/brain/ ............ EXISTING 10 tools + additive tools where needed
│
├── changes/ .............. NEW git working-tree / diff / impact (evidence-gated)
├── context-health/ ....... NEW/EXTENDED instruction conflict & health analyzer
├── secrets/ .............. NEW opt-in content secret hygiene (redacted)
│
├── monorepo/ ............. EXTEND detection → package-scoped scan orchestration
├── baseline/ ............. EXTEND verify JSON → named baselines + trends
│
├── integrations/
│   ├── github/ ........... NEW optional PR analysis (mocked tests)
│   └── local-ai/ ......... NEW optional providers (Ollama first)
│
├── dashboard/ ............ NEW local read-only UI + JSON data API
├── plugins/ .............. NEW typed SDK + discovery + capability sandbox
│
└── reporters/ ............ EXTEND human/JSON for all new report types
```

### Design invariants (non-negotiable)

1. Local-first; no mandatory cloud
2. Deterministic **core** (Safety, Brain compile, rules, Fix allowlist)
3. No mandatory API keys
4. Never print complete secrets
5. Existing CLI commands and library exports remain
6. Existing MCP tool names remain; new tools are additive
7. Safe Fix writes only allowlisted paths inside repo realpath
8. Evidence-based claims only — UNKNOWN when evidence is insufficient
9. Optional layers fail closed or degrade gracefully when disabled

### Storage layout (proposed)

```text
<repo>/.agentdoctor/
  project-brain/          # existing Brain store
  baselines/              # NEW named baselines
  fix-audit/              # NEW Safe Fix audit + backups
  secrets/                # NEW allowlists / scan cache (no secret plaintext)
  dashboard/              # NEW optional local state (no secrets)
  plugins/                # NEW discovered/enabled plugins metadata
```

Schemas versioned; migrations required; refuse silent history overwrite.
